## 主动改变的上游行为

- `tun.stack` 使用已验证的 `mixed`，不继续使用原全量脚本的 `mips`。
- 默认公共 DNS 全部加密；严格模式禁用 system-hosts 与系统 LAN DNS、保留节点的精确策略，避免按 `co.uk` 等公共后缀扩大私有 DNS 范围。
- 若部分节点有专属私有解析策略，严格模式仍给剩余节点补上机场私有解析，避免遗漏。
- 新增 `dns` 出站有实际定义，不能误把 `DNS` 当内核内置策略名称；已由 Mihomo 原生校验发现并验证。
- 原版静态 YAML 无自定义选项；本项目通过编译实现真正生效的开关，不宣称内核能原生执行任意扩展字段。
- LAN 访问改为默认关闭，常规 Apple/微软改为默认直连；海外专用服务先行。

继承的上游测试仅增加了“dns 辅助出站不是机场节点”的识别，并明确分离兼容模式回归与严格默认行为验证。未删除上游测试以凑通过率。
